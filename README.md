# Accounting & Business with Usman Khan

Responsive single-page website based on the supplied cream, beige, taupe and burgundy design reference.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive desktop, tablet and mobile styling
- `script.js` — mobile navigation, active section state and current copyright year
- `assets/usman-hero-portrait.png` — separately generated portrait asset
- `assets/usman-about-office.png` — separately generated office portrait asset

The photos are original generated assets and are not cropped from the supplied mockup.

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build tools are needed. An internet connection loads optional Google Fonts and opens the external links.

## Customize
Edit the colors in `:root` at the top of `styles.css`. Update external URLs in `index.html` if official registration or video URLs change.

## Notes
Course and resource buttons point to the supplied Linktree because separate registration URLs were not supplied. The testimonial copy is illustrative and should be replaced with verified student feedback before publishing.
